# Mount Bohemia 2026–27 partner map

Unofficial community map, compiled 2026-11-25. All 46 detailed partner offers on https://www.mtbohemia.com/season-passes/ at time of compilation. Map points are approximate, not guaranteed parking or lift access. Several were cross-checked against public location sources; remaining positions are preliminary estimates. Big Red Cats represents the office, not the staging area. Terms are summarized, not a guarantee; consult the official page.

## Publish
Create a public GitHub repository, upload index.html, partners.geojson and partners.csv to its root, then open Settings → Pages, choose Deploy from a branch, main / root and Save. GitHub will display the public URL. No backend or API key is required. Alternatively upload this folder to a static web host. Leaflet and OpenStreetMap tiles require internet access.

## Data
CSV and GeoJSON use WGS84 decimal degrees; GeoJSON coordinates are longitude, latitude. Benefit codes: 1/2/3 free days; U unlimited; D discount. Source terms: Mount Bohemia. Selected location references: Ski Area Factsheets (skiareaguide.com), Mapcarta/GeoNames/Wikidata/OpenStreetMap, Midwest Lost Ski Areas Project (mwlsap.org), British Columbia Geographical Names, North Dakota Tourism, City of Sioux Falls, and XIONIA/OpenSkiMap. Location data partly from OpenStreetMap contributors (ODbL), OpenSkiMap, Skimap.org, Who’s On First, Mapterhorn. See https://www.openstreetmap.org/copyright and https://opendatacommons.org/licenses/odbl/1-0/. The OSM-derived coordinate subset is provided under ODbL; partner terms are independently summarized.
